# Contributors

OnPrem AI Gateway is maintained by its community. This file recognizes people
and organizations that contribute code, documentation, testing, translations,
security research, design, or project stewardship.

## How to be listed

Add yourself in a pull request after your first accepted contribution, using
the format below. Listing is optional; contributors may instead use a GitHub
handle or remain unlisted.

```text
- Name or GitHub handle — contribution area(s)
```
