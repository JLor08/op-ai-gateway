# Contributing

Thank you for contributing to OnPrem AI Gateway.

## Development workflow

1. Open an issue describing the change before starting substantial work.
2. Keep pull requests focused and include tests for changed behaviour.
3. Run `go test ./...` in `backend/` and `npm run build` in `frontend/`.
4. Do not commit credentials, model prompts containing personal data, or
   customer logs.

## Recognition

After an accepted contribution, you may add your preferred name or GitHub
handle to [CONTRIBUTORS.md](CONTRIBUTORS.md). This is optional.

## Code of conduct

Be respectful, constructive, and inclusive. Report unacceptable behaviour to
the maintainers through the security contact in `SECURITY.md`.
